Engineered & Developed Solely By Kishan Nishad

The entirety of Devengers — from core system architecture, database design, backend APIs, and security infrastructure to the dark neo-brutalist user interface — was conceived, engineered, and developed solely by Kishan Nishad.

Kishan is a passionate software engineer and full-stack developer (active on GitHub as @code-with-kishan). Specializing in C++ Data Structures & Algorithms, scalable web systems, and AI-driven products, Kishan has earned global recognition in prestigious programs like Google Code Vipassana and built high-impact applications including AI Money Mentor and Suvidha Kiosk.

🛠️ What Kishan Engineered for Devengers:
  • Zero-Dependency Python Backend: Built a lightweight, blazing-fast HTTP server core with native thread-pooling, route handling, and hardened cybersecurity filters.
  • Edge libSQL Database: Integrated distributed cloud database replication on Turso across Mumbai (aws-ap-south-1) with zero cold-start latency.
  • Passwordless OTP Security: Designed transactional email authentication via Brevo API with cryptographic tokens and replay protection.
  • DSA Streak Engine: Created real-time streak computation algorithms, daily Problem of the Day (POTD) tracking, and community leaderboard systems.
  • Academic Knowledge Vault: Built a searchable archive of over 430 university previous-year papers (AKTU, MMMUT, GGSIPU, RGPV, MAKAUT, VTU) with in-browser PDF previewers.
  • Verifiable Credentials Registry: Built a digital certificate verification system with unique ledger IDs to validate student hackathon and course achievements.

As the Founder, CEO, and Sole Developer, Kishan's vision is simple: democratize computer science education so that every student engineer, regardless of college tier or socioeconomic background, has free access to top-tier preparation resources and hackathon opportunities.
